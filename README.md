# Daily Ledger Web App (`app/`)

React + TypeScript + Vite web dashboard for **နေ့စဉ် စာရင်း (Daily Ledger)**.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Ensure `api/` is running on `http://localhost:4000` (Vite proxies `/api` automatically).
3. Start development server:
   ```bash
   npm run dev
   ```
4. Build & test:
   ```bash
   npm run build
   npm test
   ```
